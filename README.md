# Pixev

Pixev is a web application designed for seamless exploration of a diverse collection of images. Users can search for images across various categories and enjoy a visually appealing and responsive experience. The application is deployed at [pixev.netlify.app](https://pixev.netlify.app).

## Features

- **Image Search**: A fast and intuitive search functionality to find images easily.
- **Diverse Categories**: Browse through various categories including:
  - Nature
  - Rainy Days
  - Wildlife
  - Mountain Views
  - Floral Wonders
  - Urban Landscapes
  - Beach Scenes
  - Night Sky
  - Historical Sites
  - Adventure
- **Responsive Design**: Ensures a smooth user experience on all devices.

Visit [pixev.netlify.app](https://pixev.netlify.app) to explore a world of captivating images.

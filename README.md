# Pixev

Pixev is a web application that allows users to search for and explore a diverse collection of images across various categories. The application is deployed at [pixev.netlify.app](https://pixev.netlify.app).

## Features

- **Image Search**: Quickly find images that match your needs using the search functionality.
- **Diverse Categories**: Explore images across categories such as Nature, Rainy Days, Wildlife, Mountain Views, Floral Wonders, Urban Landscapes, Beach Scenes, Night Sky, Historical Sites, and Adventure.
- **Responsive Design**: Enjoy a seamless experience across various devices with a responsive user interface.

## Installation

To run Pixev locally, follow these steps:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/vikash721/Pixev.git
   cd Pixev
   ```

2. **Install dependencies**:

   Ensure you have [Node.js](https://nodejs.org/) installed, then run:

   ```bash
   npm install
   ```

3. **Start the development server**:

   ```bash
   npm start
   ```

   The application will be accessible at `http://localhost:3000`.

## Deployment

Pixev is deployed using [Netlify](https://www.netlify.com/). To deploy your own version:

1. **Fork the repository** on GitHub.
2. **Connect your repository to Netlify** following their [deployment guide](https://docs.netlify.com/site-deploys/create-deploys/).
3. **Set up build settings**:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `build`
4. **Deploy the site**.
